# Barber Booking App – Low/High Fidelity Prototype

## Assignment

Using Figma, a low/high-fidelity prototype was designed for the **landing/home page** of a web application that allows users to easily book barber appointments online.

The prototype was created based on:
- Defined user personas
- Information architecture and sitemap
- Project description from previous assignments

The design applies fundamental UX/UI principles such as **consistency, readability, and visual hierarchy**, with a strong focus on **CRAP principles** (Contrast, Repetition, Alignment, Proximity).

---

## Project Overview

The **Barber Booking App** is a web-based application that enables users to:
- Browse available barbers and their services
- View prices and working hours
- Select a preferred barber
- Choose a service and available time slot
- Confirm and manage appointments online
- Leave and view reviews

The main goal of the homepage is to clearly communicate the purpose of the application and guide users toward booking an appointment quickly and intuitively.

---

## Design Requirements

The homepage must:

1. Clearly introduce the brand and purpose of the application
2. Highlight key features and services in a compelling way
3. Guide users toward conversion (e.g., *Book Now*)
4. Build trust through visuals, reviews, and clear messaging
5. Be fully responsive and accessible on desktop, tablet, and mobile devices

---

## Key User Scenarios

Users visiting the homepage should be able to:

1. Understand what the application offers within the first 3 seconds
2. Navigate to barber and service categories
3. Learn the benefits of using the application
4. Start the booking process immediately
5. Find contact information or social proof (reviews)

---

## Functional Requirements

The homepage includes:

### 1. Navigation Bar
- Application logo
- Menu links (Home, Services, Barbers, Reviews, Contact)
- Primary call-to-action button (*Book Appointment*)

### 2. Hero Section
- Large visual background related to barber services
- Clear headline and supporting subheadline
- Primary CTA button (*Book Now*)

### 3. Benefits / Value Proposition Section
- Icons or visuals
- Short explanatory texts highlighting:
  - Fast online booking
  - No phone calls or waiting
  - Verified barbers and reviews
  - Easy appointment management

### 4. Featured Content Preview
- Overview of popular services (e.g., haircut, beard trim)
- Preview of selected barbers
- CTA buttons leading to booking flow

### 5. Trust Section
- User testimonials and reviews
- Ratings and social proof

### 6. Footer
- Contact information
- Social media links
- Legal links (Privacy Policy, Terms & Conditions)

---

## Content Requirements

### Hero Section
- Headline: *Book Your Barber Appointment in Minutes*
- Subheadline: *Choose a barber, select a service, and book your time slot online*
- Primary CTA: *Book Appointment*

### Benefits Section
- 3–4 short benefit points with clear descriptions

### Content Cards
- Service or barber image
- Title
- Short description or price (if applicable)
- CTA button

---

## Interaction & UX Requirements

- Responsive layout for desktop, tablet, and mobile
- Hover states for buttons and links
- Clear visual hierarchy of elements
- Layout that encourages scrolling and exploration

---

## Accessibility Requirements

To ensure inclusive design:
- Alternative text for images
- Semantic structure (headings, navigation, footer)
- Sufficient contrast between text and background

---

## Branding & Visual Requirements

- Modern and clean visual style
- Consistent color palette and typography
- Clear typography hierarchy (H1, H2, body text)
- Consistent spacing and alignment
- Use of icons and barber-related imagery

---

## Performance Considerations

- Optimized images
- Simple and clean layout
- Smooth scrolling and transitions

---
